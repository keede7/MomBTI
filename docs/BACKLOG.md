# 다음 기획 백로그

1차 MVP에서 뺀 기능과, 기획 중 나온 개선 제안을 모아 둔다. MVP 구현 중에는 이 목록을 구현하지 않는다 (CLAUDE.md).

## 기능 후보
| 항목 | 뺀 이유 | 다음 기획 메모 |
|---|---|---|
| 운동 루틴 (주간 캘린더, 운동 목록, 세트·시간) | 사람마다 강도와 강도를 느끼는 정도가 다름 (ADR-019) | 강도 선택(가벼움/보통/힘듦) 또는 RPE 기반으로 개인화할 수 있는지 검토 |
| 운동 강도 선택 | 입력 항목 증가 | 운동 라인의 "중강도 45분" 가정을 사용자 선택으로 대체 |
| 복부 지표 (허리둘레, 허리-키 비율, 복부비만 기준) | 다이어트의 길·예측과 직접 관련이 적음 (ADR-024) | Ashwell 2012, KSSO 2022 허리둘레 기준 |
| 외식·회식 횟수 반영 | 1회 초과 칼로리에 대한 논문 기반 고정값이 없음 | 계산 반영 시 "가정" 라벨과 "회식 영향" 비교 라인 |
| 음주 반영 | 범위 축소 | 횟수 × 잔 수 × 알코올 7kcal/g로 근거 있게 계산 가능. 가장 먼저 추가할 후보 |
| 수면 | 범위 축소 | 7시간 미만이면 개선점 상위 배치 (Nedeltcheva 2010) |
| 운동 경험, 장소, 1회 시간, 부상 부위 | 운동 루틴 제외에 따라 불필요 | 운동 루틴 기획과 함께 |
| 식이 제한 (채식, 유당불내증, 알레르기) | 범위 축소 | 식단 템플릿 치환 규칙 필요 |
| 끼니 수 | 범위 축소 | 2/3/4끼 분배 템플릿 |
| 메모와 키워드 감지 | MVP는 분석에 반영하지 않음 | 2차 LLM(docs/REPORT_STRATEGY.md) 또는 키워드 → 항목 체크 제안 |
| 목표 날짜와 실현 가능성 판정 | 날짜 기준 조언이 아님 (ADR-025) | 안전 적자로 불가능하면 적자를 늘리지 않고 "안전한 최단 날짜" 제시 |
| what-if 패널 | 범위 축소 | 운동 일수, 목표 체중만 바꿔 재계산 |
| 재계산 전후 비교 | 범위 축소 (ADR-026) | 아래 "재계산 전후 비교 제안" |
| 부분 갱신 (페이지 새로 고침 없이 리포트 교체) | 범위 축소 | JS 있을 때 fetch로 fragment 교체, 없으면 전체 새로 고침 |
| 입력값 복원 (sessionStorage) | 범위 축소 | 탭 단위, 서버 전송 없음, "입력 지우기" 버튼 |
| 인쇄 CSS / PDF 저장 안내 | 범위 축소 | `@media print`로 요약과 표 중심 레이아웃 |
| 개인정보 없는 집계 메트릭 | 범위 축소 | 폼 진입, 리포트 생성, 필드별 오류 건수만. 값 기록 금지 |
| 목표 체지방률 입력 | 입력 빈도가 낮음 | 목표 체중 = 제지방량 / (1 − 목표 체지방률) |
| 건강 확인 질문 | 사용자 결정 (ADR-009) | 서비스 공개 범위가 넓어지면 재검토 |
| LLM 기반 개인화 | 1차는 규칙 기반 (ADR-002) | docs/REPORT_STRATEGY.md 2차 확장 경로 |
| 로그인, 저장, 공유 링크 | MVP 범위 밖 | 저장 도입 시 CSRF(ADR-017)와 개인정보 처리방침 재검토 |
| 증량(벌크업) 계획 | 다이어트 목적과 다름 | |

## 재계산 전후 비교 제안
리포트는 새 결과로 바꾸되, 이전 값과 나란히 보여준다. 이전 숫자는 서버에 저장하지 않고 hidden 필드로 왕복한다 (무저장 원칙 유지).
1. **변경 요약 줄**: 재계산 직후 패널 위에 표시. 예: "활동량 추가: 도달 18~23주 → 15~19주 (약 3주 단축)"
2. **요약 카드에 이전 값**: 바뀐 카드에만 "이전 22주"를 작게 표시
3. **그래프에 이전 라인**: 이전 기본 라인을 흐린 점선으로 한 번 겹쳐 표시
4. **[되돌리기] 버튼**: 직전 조건으로 돌아가기
