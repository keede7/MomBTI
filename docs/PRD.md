# PRD: MomBTI

## 목표
성별·나이·키·몸무게만으로 **하루에 얼마나 먹어야 하는지(다이어트의 길)**와 **그렇게 했을 때 몸무게가 어떻게 변하는지(예측)**를 보여줘서, 사용자가 방향을 잡고 동기를 얻게 한다.
추가 정보는 넣을수록 더 맞춤형이 되지만, 넣지 않아도 완전한 리포트를 받는다.

## 사용자
| 페르소나 | 상황 | 입력 |
|---|---|---|
| ① 처음 다이어트하는 20~30대 | 정보가 너무 많아 어디서부터 해야 할지 모름 | 필수 4개만 |
| ② 정체기에 빠진 운동인 | 체중이 안 빠지는 이유와 현실적인 기간을 알고 싶음 | 필수 + 체지방률 |
| ③ 바쁜 직장인 | 운동을 얼마나 하면 얼마나 빨라지는지 궁금함 | 필수 + 활동량 + 목표 체중 |

### 사용자 스토리
- (P0) 4개만 입력하고 20초 안에 리포트를 본다
- (P0) 3개월 동안 내 몸무게가 어떻게 변할지 2주 단위로 본다
- (P0) 언제쯤 목표에 도달하는지 본다
- (P1) 운동을 주 3·4·5일 더하면 얼마나 빨라지는지 비교한다
- (P1) 무엇을 얼마나 먹으면 되는지 본다

## 입력
### 필수 (4개)
| 항목 | 형식 | 범위 | 비고 |
|---|---|---|---|
| 성별 | 남 / 여 | | "계산 공식에 쓰는 생물학적 성별" 툴팁 |
| 나이 | 정수 | 19~80세 | "기초대사량 계산에 필요해요" 안내 |
| 키 | 소수 1자리 | 120.0~230.0cm | |
| 몸무게 | 소수 1자리 | 30.0~300.0kg | |

### 더 맞춤형으로 (선택, 3개, 항상 보임)
| 항목 | 형식 | 비고 |
|---|---|---|
| 평소 활동량 | 5단계 선택 (운동 제외) | 단계마다 하루 걸음 수와 직업 예시 |
| 목표 체중 | 소수 1자리 kg | 입력하면 "BMI 21.2 · 지금보다 −8.0kg" 미리보기 |
| 체지방률 | 소수 1자리 % | "모르면 비워두세요, 추정해 드려요" |

활동량 5단계 (Tudor-Locke 2004 걸음 수 기준, PAL은 FAO/WHO/UNU 2004 구간 안의 값)
| 단계 | 화면 문구 | PAL |
|---|---|---|
| 1 | 거의 앉아 있음 · 하루 5천 보 미만 | 1.40 |
| 2 | 사무직 + 출퇴근 걷기 · 5천~7.5천 보 | 1.55 |
| 3 | 서서 일하는 편 · 7.5천~1만 보 | 1.70 |
| 4 | 많이 움직이는 직업 · 1만~1.25만 보 | 1.85 |
| 5 | 육체노동 · 1.25만 보 이상 | 2.00 |

### 선택 항목 기본값
| 항목 | 비었을 때 | 이유 | 리포트 표시 |
|---|---|---|---|
| 활동량 | 1단계(PAL 1.40). 개인차 밴드 상단은 PAL 1.60 | 좌식 구간의 하한. 예측이 지나치게 낙관적이지 않음 | 하루 소비량에 "추정" 태그 + "활동량을 알려주면 오차가 줄어요" |
| 목표 체중 | BMI ≥ 23이면 BMI 22.0에 해당하는 체중. 18.5~22.9면 유지 모드 | KSSO 2022 정상 범위의 중간값 | "기본 목표(건강 체중)로 계산했어요" + 바꾸기 링크 |
| 체지방률 | Deurenberg 1991 추정값 | 공개 검증된 BMI 기반 공식 | 체지방률과 체지방량 라인에 "추정" 태그 |

## 리포트 구성 (위 → 아래)
1. **상단 바**: 안전 안내 한 줄("임신·수유 중이거나 치료 중이라면 시작 전에 의료진과 상의하세요"), "결과는 저장되지 않아요", 맞춤 배지("기본 분석" / "맞춤 분석 +N"), [입력 수정]
2. **요약 카드 4개**
   - 목표 도달 예상: 식단만 기준, 주차 범위와 날짜
   - 하루 섭취 목표: kcal, 소비량 대비 차이
   - 3개월 후 예상 체중: 식단만 기준, 변화량 포함
   - 주당 감량 속도: 첫 4주 평균, 안전 범위 여부
3. **변화 그래프**
   - 기본 12주, 2주 간격 (0, 2, 4, …, 12주)
   - 라인: 식단만 / 식단 + 주 3일 / 주 4일 / 주 5일 운동. 기본 표시는 식단만 + 주 4일, 나머지는 범례 토글
   - 목표선, 개인차 밴드(소비량 ±10%, 식단만 라인 기준), "현실 보정(계획의 80%만 지킨 경우 · 가정)" 토글
   - 기간 규칙은 아래 "그래프 기간 규칙" 참조
   - 같은 데이터를 2주 간격 표로 함께 렌더
   - 운동 라인 범례에 "운동 1회 = 중강도 45분(빠르게 걷기 수준) 가정" 표기
4. **단계별 목표**: 지금 → −5% → −10% → 목표. 식단만 기준 예상 시점과 날짜. 목표보다 가벼운 단계는 생략
5. **목표 도달 예측 표**: 식단만 / 주 3·4·5일. 도달 주차(범위), 예상 날짜, 첫 4주 주당 감량, 안전 범위 여부
6. **현재 상태**: BMI(범위 막대, 중립 표현), 체지방률, 기초대사량, 하루 소비량(범위). 숫자마다 "쉽게 말하면" 한 줄
7. **식단**: 하루 kcal, 탄단지(g, kcal, 비율 막대), 끼니별 한식 예시(생활 단위 + g), 끼니마다 대체 메뉴와 편의점 옵션
8. **미리 알아둘 것**: 초기 수분 감소, 하루 1~2kg 변동은 정상, 정체기가 오는 이유, 4주마다 다시 계산. FAQ 3개
   - 왜 다른 계산기보다 느리게 나오나요?
   - "추정" 표시는 뭔가요?
   - 운동 라인은 어떻게 계산했나요?
9. **더 정확하게 보기**: 비어 있는 선택 항목만 리포트 안에서 입력해 재계산. 결과는 같은 페이지를 새 결과로 교체
10. **개선할 부분**: 최대 5개 (BMI, 활동량, 단백질 등). 데이터가 없는 항목은 일반 팁으로 구분 표시
11. **근거와 면책**: 사용한 공식과 논문 목록(본문 각주와 연결), "의학적 진단이 아니며 개인에 따라 다를 수 있어요"

### 그래프 기간 규칙
- 계산은 하루 단위로 52주까지 한다. 표시는 최대 26주(6개월)까지다.
- 기간은 "식단만" 시나리오의 도달 시점(기본값)으로 판단한다.

| 도달 시점 | 그래프 | 토글 |
|---|---|---|
| ≤ 12주 | 12주, 도달 지점에 "목표 도달" 표시 | 숨김 |
| 13~26주 | 12주, 오른쪽 끝에 "목표까지 약 N주" | "6개월까지 보기" 노출 |
| > 26주 또는 미도달 | 12주, 오른쪽 끝에 "6개월 안에는 어려워요" | "6개월까지 보기" 노출. 6개월 보기에서 중간 목표(−5%, −10%) 안내 |

이유: 짧은 축에서는 초반 변화가 크게 보여서 동기 부여에 유리하다. 대신 목표가 그래프 밖에 있으면 막막하므로 6개월 토글로 이어 준다. 상세 근거는 ADR-021.

## 계산 규칙
| 항목 | 규칙 | 근거 |
|---|---|---|
| BMI | 몸무게 / 키(m)² | KSSO 2022 구간: <18.5 / 18.5~22.9 / 23~24.9 / 25~29.9 / ≥30 |
| 체지방률 추정 | 1.2 × BMI + 0.23 × 나이 − 10.8 × (남 1, 여 0) − 5.4 | Deurenberg 1991 |
| 기초대사량 | 체지방률 미입력: Mifflin-St Jeor / 입력: Katch-McArdle (370 + 21.6 × 제지방량) | Mifflin 1990, Frankenfield 2005 |
| 하루 소비량 | 기초대사량 × PAL | FAO/WHO/UNU 2004 |
| 적자 | min(소비량 × 25%, 주당 체중 1%에 해당하는 kcal ÷ 7). 65세 이상은 20% | Helms 2014 (주당 0.5~1%) |
| 하루 섭취 목표 | max(하한, 소비량 − 적자), 10kcal 단위 반올림. 하한: 여 1,200 / 남 1,500 | NHLBI 1998 |
| 운동 소비량 | (MET 4.3 − 1) × 현재 체중 × 0.75시간 × 주 N회 ÷ 7 | Ainsworth 2011 (빠르게 걷기) |
| 체중 변화 | Hall 단순화 모델 (ARCHITECTURE.md 시뮬레이션 모델) | Hall 2007, 2011 |
| 개인차 밴드 | 기초대사량 × 0.9 / × 1.1로 각각 시뮬레이션 | Frankenfield 2005 (약 ±10%) |
| 현실 보정 | 섭취 = 목표 + 20% × (소비량 − 목표) | 가정 (화면에 표기) |
| 단백질 | 1.6g × 체중. BMI ≥ 30이면 목표 체중 기준. 65세 이상은 최소 1.2g/kg | Morton 2018, PROT-AGE 2013 |
| 지방 | 섭취 kcal의 25% | IOM AMDR 2005 (20~35%) |
| 탄수화물 | 나머지 kcal. 반올림 오차는 탄수화물에서 보정 | |
| 안전 범위 | 첫 4주 평균 주당 감량 ≤ 현재 체중의 1% | Helms 2014 |

상세 목록과 다음 기획 메모는 docs/BACKLOG.md.

- 로그인, 저장, 공유, PDF, LLM 분석, 목표 체지방률, 건강 확인 질문, 증량 계획

## 성공 기준
- 필수 4개만으로 리포트 완성 (E-01)
- E-01~E-30 테스트 전부 통과
- 페르소나 3개의 결과가 수기 계산과 ±1% 이내
- 입력부터 리포트까지 20초 이내 (사용성 테스트 5명)

## 리스크
| 리스크 | 대응 |

| 예측을 보장으로 오해함 | 범위 표기, 개인차 밴드, 면책 |

| 운동 라인이 개인 강도와 다름 | "가정" 표기, FAQ 설명 (ADR-020) |
