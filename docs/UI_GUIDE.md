# UI 디자인 가이드

## 디자인 원칙
1. **체성분 검사지처럼 읽힌다.** 마케팅 페이지가 아니라 한 장으로 이어지는 결과지. 요약이 먼저, 근거는 마지막.
2. **3초 안에 핵심.** 첫 화면(360×640)에서 요약 카드 4개가 보여야 한다.
3. **필수는 필수처럼, 선택은 선택처럼.** 필수 4개는 위에 진하게, 선택 3개는 "선택" 라벨과 함께 아래에.
4. **모든 숫자 옆에 뜻을.** 숫자마다 "쉽게 말하면" 한 줄과 출처 각주.
5. **경고는 아낀다.** 상단 배너는 최대 2개. 비낙인 표현을 쓴다.
6. **JS 없이도 완전하다.** 차트가 없어도 표로 같은 정보를 본다.

## AI 슬롭 안티패턴 — 하지 마라
| 금지 사항 | 이유 |
|-----------|------|
| backdrop-filter: blur() | glass morphism은 AI 템플릿의 가장 흔한 징후 |
| gradient-text (배경 그라데이션 텍스트) | AI가 만든 SaaS 랜딩의 1번 특징 |
| "Powered by AI" 배지 | 기능이 아니라 장식. 사용자에게 가치 없음 |
| box-shadow 글로우 애니메이션 | 네온 글로우 = AI 슬롭 |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰 |
| 모든 카드에 동일한 rounded-2xl | 균일한 둥근 모서리는 템플릿 느낌 |
| 배경 gradient orb (blur-3xl 원형) | 모든 AI 랜딩 페이지에 있는 장식 |
| 빨간 경고색 남발 | 체중 이야기는 민감하다. 위험 신호는 진짜 필요한 곳에만 |

## 컴포넌트
### 결과지(시트)
```
background: var(--paper); border: 1px solid var(--line); border-radius: 6px; padding: 24px (모바일 18px)
제목 영역: 아래 2px solid var(--ink) 선
```

### 요약 카드 (4개 한 묶음)
```
하나의 테두리 박스를 4칸으로 나눈다 (카드마다 그림자·둥근 모서리 금지)
라벨 12px 600 var(--ink-3) / 큰 숫자 24px 600 모노 / 보조 12px var(--ink-3)
데스크톱 4열, 모바일 2×2
```

### 범위 막대 (BMI, 체지방률)
```
높이 10px 구간 막대 + 현재 위치 핀(2px × 20px var(--ink)) + 구간 라벨 11px
구간 이름은 중립 표현: 저체중 / 정상 / 관리 권장 / 관리 필요 / 적극 관리
```

### 태그
```
"추정": 11px 600, 점선 테두리 var(--warn)
"가정": 11px 600, 점선 테두리 var(--ink-3)
"선택" / "필수 4개": 11px 600, 실선 테두리
```

### 버튼
```
Primary: background var(--ink); color var(--paper); border-radius 4px; padding 11px 20px; font-weight 600
Ghost:   background transparent; border 1px solid var(--line); color var(--ink)
토글(범례, 기간): pill 형태, aria-pressed로 상태 표시, 꺼짐은 opacity .45
```

### 입력 필드
```
border 1px solid var(--line); border-radius 4px; padding 9px 10px
단위 접미사(cm, kg, %, 세)를 필드 안 오른쪽에 표시
숫자 필드는 inputmode="decimal" (나이는 numeric)
포커스: border-color var(--accent) / 오류: border-color var(--crit) + 아래 12px 오류 문구
성별: 세그먼트 버튼 (선택 시 var(--ink) 배경)
```

### 각주
```
본문 숫자 뒤 위첨자 [n] 11px 모노 var(--accent) → 근거 목록 #refN 앵커
```

## 레이아웃
- 전체 너비: 최대 960px, 단일 컬럼
- 정렬: 좌측 정렬 기본. 중앙 정렬 금지 (빈 상태 문구 포함)
- 간격: 섹션 간 18~20px, 섹션 안 12px. 형제 요소는 flex/grid gap으로 배치
- 좌우 여백: 최소 16px (`max(16px, env(safe-area-inset-*))`)
- 반응형 기준: 360 / 768 / 1024px. 760px 이하에서 카드 2×2, 입력 2열, 표는 가로 스크롤 컨테이너 안에서만
- 리포트 섹션 순서는 docs/PRD.md "리포트 구성"을 따른다

## 그래프
- 기본 12주, x축 눈금은 2주 간격. 6개월 보기에서는 4주 간격 눈금
- 기본 표시: 식단만 + 주 4일. 나머지는 범례 토글
- 개인차 밴드: 식단만 라인 색의 15% 투명도
- 목표선: var(--target) 1.5px 점선
- 도달 지점: 작은 원 마커 + "목표 도달" 라벨
- 12주 밖 목표: 그래프 오른쪽 끝에 "목표까지 약 N주" 라벨
- 툴팁: "N주 후 · 2027년 3월 둘째 주 / 식단만: 78.4kg"
- 축과 라벨 색은 토큰(var(--ink-3), var(--line))에서 읽어 다크모드에서도 보이게
- 차트 아래에 같은 데이터의 표를 항상 렌더 (`<table>`, 2주 간격 행)
- 애니메이션 끔 (`animation: false`)

## 문구 톤
- 존댓말 "~해요"체. 짧고 직접적으로
- 오류 메시지는 "무엇이 + 어떻게": "m가 아닌 cm로 입력해 주세요 (예: 175)"
- 금지 표현: "비만입니다", "위험합니다", "실패", "반드시", 사과 문구 ("죄송합니다")
- 체중 구간은 중립 표현 ("체중 관리가 권장되는 구간")
- 가정과 추정은 숨기지 않고 태그로 드러낸다

## 애니메이션
- 앵커 이동 시 부드러운 스크롤 (`prefers-reduced-motion`이면 끔)
- 그 외 모든 애니메이션 금지 (차트 애니메이션 포함)

## 아이콘
- 아이콘을 쓰지 않는다. 필요하면 SVG 인라인, strokeWidth 1.5
- 아이콘 컨테이너(둥근 배경 박스)로 감싸지 않는다
- 이모지를 섹션 표시로 쓰지 않는다

## 접근성
- 모든 입력에 label-for, 힌트와 오류는 aria-describedby
- 오류 발생 시 상단 오류 요약(앵커 링크) + 첫 오류 필드에 포커스
- 토글은 aria-pressed, 탭은 role="tab" + aria-selected
- 포커스 링은 지우지 않는다 (`:focus-visible { outline: 2px solid var(--accent) }`)
- 차트 canvas에 aria-label + 아래 표가 대체 콘텐츠
