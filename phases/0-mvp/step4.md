# Step 4: advice

## 목표
식단, 개선할 부분, 조언 문장을 `core/domains/report/advice/`에 구현한다.

## 작업
- `MealPlanCatalog`
  - 칼로리 구간별 한식 끼니 템플릿 (1,200~3,600kcal, 200kcal 간격 정도). 아침·점심·저녁·간식, 생활 단위 분량(밥 2/3공기 등), 대체 메뉴, 편의점 옵션
  - 범위 밖이면 가장 가까운 템플릿을 비율로 조정 (E-22)
  - 템플릿은 코드 상수 또는 `src/main/resources`의 데이터 파일
- `ImprovementRuleEngine` (Rule 인터페이스): BMI, 활동량, 단백질 등 최대 5개. 데이터 없는 항목은 일반 팁으로 구분 (PRD 리포트 구성 10)
- `AdviceNarrator` 인터페이스 + `TemplateAdviceNarrator`
  - 계산된 값만 문장에 넣는다. 숫자를 새로 만들지 않는다
  - 문구 톤은 docs/UI_GUIDE.md "문구 톤" (존댓말 "~해요", 금지 표현 없음)
  - 미리 알아둘 것(초기 수분 감소, 하루 변동, 정체기, 4주마다 재계산)과 FAQ 3개(왜 느리게 빠지나요 / 운동 라인 강도 기준 / 탄수화물 비율이 왜 낮은가요)
  - 모든 지표 건강 범위 + 목표 없음 → 긍정 빈 상태 문구 (E-30)

## 테스트 (먼저 작성)
- `E22_목표_kcal이_템플릿_범위_밖이면_가까운_템플릿을_비율로_조정`
- `E30_모든_지표가_건강_범위이고_목표가_없으면_긍정_문구`
- 식단 합계 kcal이 목표 대비 ±5% 이내
- Narrator 출력에 금지 표현("비만입니다", "위험합니다", "실패", "반드시", "죄송합니다")이 없음
- 개선점 최대 5개
